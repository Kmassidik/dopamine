# DECISIONS

Format: date, step, decision, options, reason, consequences / how to reverse.

## 2026-11-15, Step 1: two repos, manifest at repo root
- **Decision:** `dopamine-content` holds `manifest.json` at its root, generated from `catalog.json` plus lesson files.
- **Options:** `content/manifest.json` subfolder (as in the brief); root.
- **Reason:** the repo is already the content repo; raw URL is `.../main/manifest.json`.
- **Reverse:** move files and change `CONTENT_BASE_URL`.

## 2026-11-15, Step 2: toolchain
- **Decision:** AGP 9.5.1, Gradle 9.9.1, Kotlin 2.4.21, compileSdk/targetSdk 37, built on the Nix JDK 25 via `build.sh`.
- **Options:** JDK 17, a second user-local JDK. Rejected: the Nix JDK 25 already works with this AGP/Gradle.
- **Reason:** latest stable versions looked up from Maven, not guessed. Kotlin 2.5.0 is only an RC.

## 2026-11-15, Step 2: no auto backup
- **Decision:** `allowBackup=false`.
- **Reason:** privacy and simplicity. Progress backup will be explicit export/import (Settings, planned).
- **Reverse:** enable backup and add data extraction rules excluding any token.

## 2026-11-15, Step 2: release APK signed with the debug key
- **Reason:** personal sideload; `assembleRelease` yields an installable APK. Use a real keystore for sharing.

## 2026-11-15, Step 2: math renderer candidate
- **Decision (provisional):** `ru.noties:jlatexmath-android 0.2.0` (650 KB, native). Last release 2020.
- **Risk:** unmaintained. **Fallback:** vendor and patch it, or a hand-rolled layout for the subset we use. Verified in Step 3 against the 25-formula screen.

## 2026-11-15, design change (user request): white, green, yellow, pink
- **Decision:** replace the Japanese washi/ink theme with a white background and three accents (green #35C46F, yellow #FFC93C, pink #FF7FAE), chunky rounded shapes, dark ink text on every fill.
- **Reason:** the user asked for white with a 2026 look in those colors.
- **Consequences:** deviates from sections 17 and 18 of the original brief (palette, motion ideas, icon STYLE block). Text colors use deeper tones so every pair passes WCAG AA (enforced by `ContrastTest`). Font stays Zen Maru Gothic (OFL), Latin subset 22 KB per weight.

## 2026-11-15, Step 5/10 early: content as files, no Room yet
- **Decision:** the first working build reads content straight from `filesDir/content` and has no database yet.
- **Reason:** get seed loading and Update working before progress exists. Room arrives with progress (Step 4, moved later).
- **Consequences:** progress, hidden lessons and update logs are not persisted yet. Removed lessons simply disappear from the manifest and stay on disk.

## 2026-11-15, Step 10 early: update is staged and swapped
- **Decision:** copy current content to `content.stage`, apply verified downloads, then rename-swap into `content`.
- **Reason:** any failure discards the stage; the live content is never partially written.
- **Safety rules:** HTTPS only, no redirect to HTTP, strict relative path regex, size caps (manifest 512 KB, lesson 256 KB, image 1 MB), sha256 and declared size must match, lessons must parse and validate.
- **Not yet done:** resume of partial downloads, mobile-data warning, low-storage check, MockWebServer tests, update log table.

## 2026-11-15, assets: 4x4 sheets
- **Decision:** icon sheets are 4x4 (16 icons) on #FF00FF, 7 sheets, generated by the user. `tools/make_assets_md.py` is the single source for prompts and name lists.
- **Reason:** user request (more icons per sheet, subjects: math, English, software engineering, electronics).

## 2026-11-16, assets: colorful Bots style, wired in
- **Decision:** icons are the colorful "Bots" style (black outline, tiny dot-eye faces, ground shadow, spark ticks, green/yellow/pink fills), 7 sheets x 16 sliced to WebP in `res/drawable-nodpi/`. The Bot robot is the mascot and the launcher icon (yellow tile).
- **Options considered:** mono Bots, mono + pink accent, toy 3D without faces. The user chose colorful Bots.
- **Size:** 192 px icons, 256 px mascot, WebP q80. Total about 1.05 MB, a little over the 1 MB target; the release APK is 1.66 MB, far under 15 MB.
- **Gaps:** no dedicated science icon, so `ic_science` maps to the lab flask (`ic_test`). Functional glyphs (back, chevron, check, download, warning) remain tinted vectors.
- **Motion:** icons bob gently and cards squash on press; both are disabled when the system animator scale is 0. Raw sheets live in `sheets-src/` (not committed).
